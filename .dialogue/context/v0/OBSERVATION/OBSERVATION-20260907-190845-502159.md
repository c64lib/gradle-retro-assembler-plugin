Observation: the PLAN-0017 test hardening caught real defects before merge, derives from DECISION-20260907-163802-748410. (1) DasmOperatingSystem.detect classified macOS 'Darwin' as WINDOWS because 'darwin' contains 'win' - fixed by matching mac/darwin before win. (2) RetroAssemblerPlugin.apply eagerly builds KickAssemblerSettings via SemVer.fromString(dialectVersion), so a dialect = Dasm project (which has no reason to set the KickAssembler dialectVersion, default 'latest') crashed at Gradle configuration time with 'Cannot determine version from latest' - fixed by falling back to SemVer.fromStringOrNull ?: SemVer(0,0) under the Dasm dialect only. Also platform note: File.path backslashes on Windows broke string-based path assertions; DownloadDasmUseCase now threads the forward-slash string path instead of File.path.
